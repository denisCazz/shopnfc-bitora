# Avvisi Implementation Plan

> **For agentic workers:** Implement task-by-task. Steps use checkbox syntax.

**Goal:** Admin-managed popup announcements with audience, schedule, severity, and dismiss-once localStorage behavior.

**Architecture:** Drizzle table `announcements`; admin CRUD at `/admin/avvisi` via server actions; `GET /api/announcements`; client `AnnouncementPopup` in `AppProviders` keyed by pathname surface.

**Tech Stack:** Next.js App Router, Drizzle + Postgres, Tailwind, lucide-react

## Global Constraints

- Plain text messages only
- Audience: `users` | `admin` | `both`
- Severity: `info` | `warning` | `critical`
- Follow existing admin categories CRUD style
- No new npm dependencies
